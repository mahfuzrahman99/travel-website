## Overview
Wanderlust Travels is a modern, fully responsive travel booking website built with Next.js, React, and Tailwind CSS. It enables users to explore travel destinations, discover curated tour packages, and book their dream vacations with a clean and interactive user experience.

---

## Features

- **Authentication**: User sign-up/sign-in with social login options
- **Destination Discovery**: Explore featured destinations with image galleries and details
- **Tour Packages**: View comprehensive tour packages including pricing and itineraries
- **Booking System**: Book travel with an interactive form, calendar selection, and promo code support
- **Interactive Modals**: Resizable, draggable modals for content such as galleries, articles, and testimonials
- **Newsletter & Contact**: Contact form and newsletter subscription included
- **Dark/Light Theme**: Toggle theme with system preference support

---

## Tech Stack

- **Framework**: Next.js 14
- **Frontend**: React 18, Tailwind CSS, shadcn/ui
- **Icons**: Lucide React
- **Date Handling**: date-fns
- **Deployment**: Vercel

## Installation

```bash
git clone https://github.com/yourusername/wanderlust-travels.git
cd wanderlust-travels
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Core Components

- **Header**: Responsive navigation with authentication
